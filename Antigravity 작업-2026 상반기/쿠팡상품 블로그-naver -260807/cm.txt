파트너스 최종 승인이 나면서 Open API 키를 받았다. 가장 큰 수동 병목이 사라졌다.

## coupang_api.py 신설
HMAC-SHA256 서명으로 딥링크 API 를 호출한다.
signed-date 는 반드시 GMT 다 — 로컬 시각을 쓰면 서명이 어긋나 401 이 난다.

기존 브라우저 방식과 비교(실측):
  브라우저  18건 / 약 10분 / 매번 사람이 로그인 / 상품 매칭 실패 10%
  API      15건 / 약 4초  / 로그인 불필요      / 매칭 과정 자체가 없음

daily_links.py 는 키가 있으면 API 를 먼저 쓰고, 실패하면 브라우저로 넘어간다.
이로써 run_all.py 에 남는 수동 단계는 티스토리 로그인 하나뿐이다.

API 로 안 되는 상품이 있다(생리대·임신테스트기·살충제 등 5건).
카테고리 제한으로 보이며, 그런 건 브라우저 폴백으로 처리한다.

set_coupang_api.py: 키를 넣고 즉시 검증한다. 통과했을 때만 저장하고 실패하면 되돌린다.

## 제목에서 [광고] 제거
파트너스 가이드와 공정위 지침 모두 표시 위치를 '제목 또는 게시물 첫 부분' 중
하나로 정한다(둘 다 요구하지 않는다). 이 시스템은 고지를 본문 맨 위에 본문과 같은
크기로 넣으므로 제목 표시는 불필요하고, 40자 제한을 4자 아끼는 편이 낫다.

대신 check_disclosure 를 조건부로 바꿨다 — 제목 표시가 없으면 본문 고지가 유일한
표시이므로 위치를 더 엄격히 본다(120자 -> 40자).

## 카테고리 분류 보강
쿠팡 category 가 비어 있는 상품이 전부 기본값 '쿠팡 할인물품' 으로 떨어졌는데
티스토리에 그 분류가 없어 4건이 카테고리 없이 발행됐다.
상품명 키워드를 대폭 보강해 실측 79건 미분류 0건이 됐다.
겹치는 낱말은 _CATEGORY_RULES_LATE 로 분리했다.
