# Ad Studio 로컬 크롤러 도우미

Ad Studio 웹의 **URL 분석**을 강화하는 선택 설치 프로그램입니다.

## 왜 필요한가요?

| 페이지 | 기본 URL 분석 | 도우미 실행 중 |
|---|---|---|
| 일반 기업 홈페이지·블로그 | ✅ | ✅ |
| 네이버 스마트스토어/브랜드스토어 | ❌ (봇 차단) | ✅ |
| 쿠팡 등 대형 커머스 | ❌ (봇 차단) | ✅ |
| SPA 사이트 (React 등) | ❌ (빈 HTML) | ✅ |

AI 서버의 크롤러는 네이버 등에서 차단당하지만, 이 도우미는 **사용자 PC의
실제 브라우저(Playwright Chromium)** 로 페이지를 열기 때문에 일반 방문자와
똑같이 읽을 수 있습니다.

## 사용법

1. `실행하기.bat` 더블클릭 (첫 실행 시 자동 설치 — 몇 분 소요)
2. 창을 열어둔 채 Ad Studio에서 평소처럼 URL 분석
3. Ad Studio가 자동으로 도우미를 감지해 사용합니다 (별도 설정 불필요)

도우미가 꺼져 있으면 Ad Studio는 기존 방식(Gemini URL 읽기)으로 자동 폴백합니다.

## 동작 방식

- `127.0.0.1:8791` 에서만 수신 (외부 접속 불가)
- Ad Studio 웹앱 출처(headjim-adstudio.web.app, localhost)의 요청만 허용
- 페이지를 헤드리스 크롬으로 열어 렌더링된 본문 텍스트만 추출해 반환
- 이미지·폰트·미디어는 다운로드하지 않음 (속도·트래픽 절약)

## 주의

- 한 번에 한 페이지를 읽는 용도입니다. 대량 수집 용도로 쓰면 사이트가
  CAPTCHA를 띄우거나 차단할 수 있습니다.
